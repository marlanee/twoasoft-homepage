# AI 협업 방식 — GPT 지휘 · Claude 실행

이 프로젝트에서는 AI 두 개에 역할을 나눴습니다. 한 모델이 계획하고 스스로 "됐다"고 판단하는 구조를 피하려는 목적이었습니다.

| 역할 | 담당 | 하는 일 |
|---|---|---|
| 지휘자 | GPT (Codex CLI, high reasoning) | 목표·범위·금지사항·완료 기준을 담은 **TASK PACKET** 작성. 결과의 근거를 원자료와 대조해 **승인 / 조건부 승인 / 반려** |
| 실행자 | Claude (Claude Code) | 조사·구현·대시보드 조작·배포·검증. 증거·편차·미검증 항목을 담은 **CLAUDE RESULT** 보고 |
| 사람 | 프로젝트 담당자 | 로그인과 비밀번호 입력, 업체 연락, 공개 범위·문구 같은 최종 결정 |

## 원칙
- **실행 권한 분리:** GPT는 읽기 전용 샌드박스에서만 실행했습니다. 파일 수정이 필요할 때만 작업 폴더 쓰기를 허용했고, 배포·로그인·git은 금지했습니다.
- **동의는 증거가 아니다:** 실행자는 지휘자의 지시에 무조건 따르지 않습니다. 원자료와 다르면 편차와 근거를 보고합니다.
- **미검증은 미검증이라고 쓴다:** 실제로 실행한 것, 추론한 것, 하지 않은 것을 나눠 적습니다.
- **자격증명은 사람만:** 비밀번호와 인증코드는 AI가 다루지 않았습니다.

## 작업 기록

| ID | 작업 | 결과 |
|---|---|---|
| T1 | 배포 준비: `_headers`(CSP 해시·HSTS·캐시), canonical, `robots.txt`, `404.html` | 승인 |
| T1b | 404 페이지 스타일 보완, 미리보기 주소 noindex | 승인 |
| T3 | Pages → Workers Static Assets 전환(`wrangler.jsonc`) | 승인 |
| T4 | 본사·지사 주소 갱신, 지도 임베드 교체 | 승인 |
| T5 | 로고·아이콘 SVG 재작성(CSP 때문에 `style` 속성 없이 표현 속성만 사용) | 승인 |
| T6 | HTTPS·도메인 이전 전체 런북(8단계, 롤백 포함) | **조건부 승인** → 원장 증거·인증서 재검사 원문 보강 |
| T7 | "DNS 권한 없이 다른 경로는 없나?" 반례 탐색 | 대안 대부분이 업체 협조가 필요한 조건부임을 확인. 관리 계정 변경·인증코드 이전 절차를 추가로 발견. 네임서버 변경 채택 |
| T8 | 인사말 교체(사용자 원문 그대로) | 승인 |
| T9 | 보도사진 교체·사업영역 문구 초안 | 사진은 **반려**(게재 권한 미확인). 문구는 "인사말에 근거 없는 사업 확대 표현"을 지적받아 수정안 채택 |
| T10 | 권한 확인 후 재검토 | 승인 |
| T11 | 수상 캡션(1차 출처 기사와 대조), 본사/지사 지도 전환 버튼 | 승인 |
| T12 | 사진 원복, 제목 대소문자 수정 | 승인 |

## 반려·조건부 승인에서 배운 것
- **T6 조건부 승인:** "결과 보고서에만 있고 원문이 없는 증거는 증거가 아니다." 이후 모든 검증에서 명령 원문, 시각, 종료 코드를 남기도록 바꿨습니다.
- **T9 문구 지적:** 제가 쓴 초안의 "자율 보안·N2SF 기술 **개발**"은 인사말의 "**대응·지원**"보다 사업 범위를 넓히는 표현이었습니다. 사실을 꾸미지 않도록 근거 문장에 있는 범위만 남겼습니다.
- **T9 사진 반려:** 보도사진은 촬영 주체에 권리가 있습니다. 화면에 잘 나오는지보다 게재해도 되는지를 먼저 확인했습니다.
